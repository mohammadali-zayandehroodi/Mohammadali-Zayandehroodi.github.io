# Mohammadali Zayandehroodi — Academic Website

A dependency-free academic website prepared for GitHub Pages. Includes About, Publications, Research, CV, Awards, Teaching and Mentorship pages, and the original downloadable CV.

## Publish on GitHub Pages

1. Create a GitHub repository named `YOUR-USERNAME.github.io`, replacing YOUR-USERNAME with your actual GitHub username.
2. Upload the contents of this folder to the repository root (not the enclosing folder). Include `.nojekyll`.
3. In the repository, open Settings → Pages. Select Deploy from a branch, then `main` and `/ (root)`, and save.
4. Your site will be available at `https://YOUR-USERNAME.github.io/` after GitHub finishes deployment.

## Customize

Edit the HTML files directly. Shared styles are in `assets/style.css`. Replace the initials block in each page with a profile image when you have one. Replace the PDF in assets when you update your CV.

Content was transcribed from the supplied CV. Review publication author spellings, dates, mentorship categories, and current affiliation before publishing. No unverified social-profile links or profile photograph were added.

The layout is inspired by the conventional academic sidebar structure of the supplied reference. It does not copy that researcher's content or depend on Jekyll/AcademicPages.
